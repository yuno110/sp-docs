# 작업 체크리스트 — sp-docs

`D-xx`(정본 개정) 항목의 **상태 원본은 이 파일 하나뿐이다.** 다른 곳에 상태를 적지 않는다([../plan/README.md](../plan/README.md) §상태의 위치).

항목의 산출물·완료 기준·검증은 [../plan/phase1.md](../plan/phase1.md) §3(D-01)과 **§6 끝의 D-02~D-05 절**에 있다. **항목을 더할 때 이 줄과 아래 면제 줄을 같은 편집에서 본다** — 목록만 고치면 이 파일이 자기가 추적하는 항목의 기준 위치를 말하지 않게 된다(D-02 2라운드가 잡았다).

**D-02~D-05 는 1차 완료를 막지 않는다.** [../plan/phase1.md](../plan/phase1.md) §7 의 1차 완료 조건은 `AU-xx`·`M-xx`·`B-xx`·`I-xx` 이고 그 넷은 모두 `done` 이다. **D-02·D-03 은 통합 검증(I-04·I-05)이 찾았고 D-04·D-05 는 D-02 리뷰가 찾았다.** 네 항목 모두 1차 완료 **뒤에** 처리한다.
