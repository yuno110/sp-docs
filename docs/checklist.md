# 작업 체크리스트 — sp-docs

`D-xx`(정본 개정) 항목의 **상태 원본은 이 파일 하나뿐이다.** 다른 곳에 상태를 적지 않는다([../plan/README.md](../plan/README.md) §상태의 위치).

항목의 산출물·완료 기준·검증은 [../plan/phase1.md](../plan/phase1.md) §3(D-01)과 **§6 끝의 D-02~D-14 절**에 있다. **항목을 더할 때 이 줄과 아래 면제 줄을 같은 편집에서 본다** — 목록만 고치면 이 파일이 자기가 추적하는 항목의 기준 위치를 말하지 않게 된다(D-02 2라운드가 잡았다).

**D-02~D-14 는 1차 완료를 막지 않는다.** [../plan/phase1.md](../plan/phase1.md) §7 의 1차 완료 조건은 `AU-xx`·`M-xx`·`B-xx`·`I-xx` 이고 그 넷은 모두 `done` 이다. **D-02·D-03 은 통합 검증(I-04·I-05)이 찾았고 D-04·D-05 는 D-02 리뷰가 찾았다. D-06 은 M-12 구현 워커가, D-07 은 B-12 구현 워커가 찾았다. D-08 은 확인용 프론트엔드(`yuno110/sp-frontend`)를 만든 작업이 찾았다. D-09 는 사용자의 승격 지시가 만들었다 — 결함이 아니라 범위 결정이다. D-10 은 D-08·D-09 의 리뷰가, D-11 은 화면으로 확인하던 중의 실측이 찾았다. D-12 는 사용자가 2차를 시작하며 정했다. D-13 은 F-02 가 예고했고, D-14 는 F-06 의 구현 워커가 찾았다.** 1차 완료 **뒤에** 처리한다.
