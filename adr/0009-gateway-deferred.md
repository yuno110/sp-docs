# 0009. API Gateway 2차 이연

## 상태
accepted

## 맥락

MSA의 표준 구성에는 API Gateway가 들어간다. 단일 진입점, 라우팅, CORS 일괄 처리, 1차 JWT 검증을 담당한다. 1차부터 둘지 정해야 했다.

## 결정

**1차에서는 게이트웨이를 두지 않는다.** 클라이언트가 `:8081`(member), `:8082`(board)를 직접 호출한다.

## 근거

- 서비스가 2개뿐이라 프론트엔드가 주소 2개를 아는 것으로 충분하다
- 게이트웨이는 Spring Cloud Gateway를 쓰게 되는데, **Spring Cloud 릴리스 트레인은 Boot 버전과 강하게 결합**되어 업그레이드 부담을 만든다. 1차에 도입을 미루면 그 결합을 피할 수 있다
- 게이트웨이가 없어도 각 서비스가 JWT를 독립 검증하므로 보안이 약해지지 않는다. 오히려 Zero Trust 원칙상 **게이트웨이가 있어도 각 서비스는 재검증해야** 한다

## 결과

- `gateway/` 디렉터리를 만들지 않는다
- **CORS를 각 서비스가 개별 설정한다.** 게이트웨이 도입 시 이 설정을 게이트웨이로 옮긴다
- Spring Cloud 의존성을 1차에 도입하지 않는다
- [../api-contract.md §1](../api-contract.md)의 경로 표는 2차 전환 시 게이트웨이 라우팅 규칙의 명세가 된다

## 그 뒤에 바뀐 것 — 수가 낡았다 (2026-10-20)

**위의 결정과 근거를 고쳐 쓰지 않는다.** 그때의 판단을 남기는 기록이고, 결정("1차에 게이트웨이를 두지 않는다")은 지금도 유효하다. 다만 **근거에 적힌 수가 낡았다.**

| 이 문서가 적은 것 | 무엇이 낡았나 |
| --- | --- |
| "클라이언트가 `:8081`(member), `:8082`(board)를 직접 호출한다" | **열거가 빠졌다** — auth 가 자기 포트를 갖는다 |
| "서비스가 2개뿐이라 프론트엔드가 **주소 2개**를 아는 것으로 충분하다" | **그 수가 늘었다.** 지금 몇인지는 여기 적지 않는다 — 적으면 다음 서비스가 그것을 또 낡게 만든다([../conventions.md §9.5](../conventions.md)) |

[0012](0012-auth-as-separate-service.md)가 auth 를 별 서비스로 떼어내면서 늘었다. **주소와 그 개수를 이 문서에서 가져오지 않는다** — 정본은 [../api-contract.md §1](../api-contract.md)의 경로 표이고, 거기를 보면 지금 몇인지 알 수 있다.

**결정이 유효한 이유는 그대로다.** "주소 2개면 충분하다" 가 아니라 **게이트웨이 도입이 Spring Cloud 릴리스 트레인과 Boot 버전의 결합을 들여온다**는 쪽이 결정을 지탱한다. 주소가 늘면서 클라이언트가 아는 것도 늘었으므로, **서비스가 더 늘거나 클라이언트가 둘 이상이 되면 이 결정을 다시 본다.**

**클라이언트가 제품이 된 것 자체는 재검토 사유가 아니다.** 비용이 오르는 것은 **주소를 아는 자리가 늘 때**이고, 그 수는 분류가 아니라 **서비스·클라이언트의 개수**가 정한다. 제품이 되면서 새로 생기는 것은 배포 오리진이 하나 늘어나는 것뿐이고, 그것은 CORS 환경값이 이미 받는다([../security.md §1.1](../security.md)). **분류가 바뀌었으니 결정도 다시 본다** 는 추론은 그 자리에서 일하지 않는다.

> **프론트엔드가 2026-10-20 에 생겼다**(`yuno110/sp-frontend`, [../overview.md §2](../overview.md)). 같은 날 확인용 도구로 시작해 **제품 화면으로 승격됐다**([../plan/phase1.md](../plan/phase1.md) D-08·D-09). 그 화면이 각 서비스의 주소를 직접 안다 — 이 ADR 이 "충분하다" 고 본 상태를 실제 클라이언트가 밟는다. 그쪽은 **경로 접두어 → 서비스 배정을 코드에 모으고 주소는 환경값으로 뺐다** — 게이트웨이를 도입하면 그 배정이 라우팅 규칙으로 옮겨간다. **어디에 몇 벌 있는지는 여기 적지 않는다**([../conventions.md §9.5](../conventions.md)) — 그 저장소의 사정이고, 개발 서버의 프록시 설정처럼 같은 배정을 다른 목적으로 또 갖는 자리가 있을 수 있다.

## 도입 시점

2차. 도입 시 `/internal/**`을 라우팅에서 제외해 내부 API의 외부 노출을 차단한다.
